# 📈 finance-trak

`finance-trak` is a deployable service, written for the APACHE - _*AMPP_ environment. Which **help track your financial balance** in a simplistic user interface which does accurate and real time reports for you.

_I used to track my finances in a spreadsheet document, using custom written functions and all to archieve similar features but I decided to create my custom little service for it, that I can deploy on my home server._

> [!IMPORTANT]  
> This software was made to satisfy my finance tracking needs. Maybe this is not the tool for you, so keep that in mind. I decided to Open Source my project so anybody can use it or modify it according to their needs. If this project is sampled or used in a commercial / public project I require attribution in form of a link to this repository.
